# Game Launcher

A desktop game launcher that allows users to sign in with their existing account and launch the game directly.

## Features

- Secure account sign-in via OAuth 2.0
- Automatic profile and skin loading after login
- Lightweight desktop client
- Cross-platform support (Windows / Linux / macOS)

## Status

This project is currently in active development. The authentication module is being prepared for API access review.

## Tech Stack

- Desktop application framework
- OAuth 2.0 public client flow
- Local callback listener on `http://localhost`

## Getting Started

1. Clone the repository
2. Install dependencies
3. Run the launcher in development mode
